100 Verbe · v3 — приложение для изучения румынских глаголов

Откройте index.html после публикации на HTTPS-хостинге (адрес должен начинаться с https://).
В Chrome на Android нажмите «Разрешить микрофон» и подтвердите доступ.
Затем нажмите «Произнести слово» или «Произнести».

Голосовой ввод может зависеть от браузера и поддерживаемого сервиса распознавания.
HTTPS необходим для стандартного доступа к микрофону, но не гарантирует правильную работу распознавания.
Карточки и переводы работают автономно; для воспроизведения используется синтетический голос и резервное аудио.
Прогресс сохраняется только в локальном хранилище текущего браузера/адреса. При переходе с файла на сайт он не переносится автоматически — используйте экспорт/импорт прогресса.

Публикация: распаковать ZIP, загрузить index.html на статический HTTPS-хостинг (например, GitHub Pages).
Этот архив сам по себе НЕ создаёт работающий HTTPS-адрес. Настроить и включить публикацию нужно отдельно.

Приватность: при использовании браузерного распознавания Chrome аудио может отправляться на сервер службы распознавания. Статическая страница не требует собственного сервера для хранения аудиофайлов.
